# @simple-reporting/create

Creates a new Simple Reporting Library 2 project.

```bash
npm create @simple-reporting@alpha my-report
# options: --livingdocs <npm package>|none  --yes  --no-install  --no-git
```

It copies the project template, installs `@simple-reporting/core` and
`@simple-reporting/livingdocs`, installs the default livingdocs components and initialises git.
